## 🔴 硬件 API 关键规格（三个 zip 完整研读，2026-08-16）

### 机械臂 FTArm B9（HTTP :8087）
- 阻塞式 REST：end_effector 60s 上限 / joints 无上限 / playback 300s
- **WebSocket 异步控制无 60s 限制**（长距离运动用 WS）
- **示教+回放**：/api/teach_mode 进入零力矩拖动录制 → /api/teach save → /api/playback 回放
  ——现场调试利器！人工拖动录轨迹，回放时自动平滑+自碰撞检查
- 安全开机流程：motors 检查(has_feedback=1, fault=0) → enable → plan_only 预览 → 低速执行
- 直线验证：message 含 `OMPL` 即回退非直线（客户端断言）
- cancel 只复位软标记不停运动；真停 = 新目标抢占或 disable（⚠️掉臂）
- 关节限位：shoulder_pitch ±2.0 / shoulder_roll -0.2~2.0 / shoulder_yaw ±2.0 / elbow_roll ±1.2 / elbow_yaw ±2.0 / wrist_pitch ±1.1 / wrist_yaw ±1.1
- ErrorCode：0=成功 1=INVALID_GOAL 2=PLANNING_FAILED 3=EXECUTION_FAILED 4=CANCELED 5=IK_FAILED 6=EXCEPTION

### 灵巧手 O10（HTTP :8088，7.29 更新版附件）
- POST /api/set_pos 请求体 `{"position": float[10]}`（归一化 0-1，10 自由度）
- **归一化语义（数学换算确认）**：position=1 → 最大弧度 → 弯曲/握拳；position=0 → 张开
  ⚠️ 官方文档 curl 示例注释写反了（"张手"示例给 [1,1,...]），以关节弧度数学换算为准
- 错误码 5 位 bitmask：堵转1/过热2/过流4/电机异常8/通讯异常16
- WebSocket ws://<IP>:8088/ws 50ms 推送；set_motor 极限值会堵转（禁用）
- 混合控制 set_pvc 支持 torque 电流前馈 (mA 0-1000)

### Fourier DexHand SDK（仅背景，决赛不用）
- UDP 协议直连（默认左手 192.168.137.19 / 右手 192.168.137.39），仅 Linux .so
- 型号：FDH6（6DOF）/ FDH12（12DOF），有触摸传感器矩阵 get_ts_matrix
- 决赛现场组委会已桥接为 HTTP API（这正是 7.29 更新"移除原 SDK"的原因）

### 接口测试工具（8.3 发布）

- contestant_mock_server.py：模拟成功/失败/HTTP错误/无效JSON/空响应 5 种模式
