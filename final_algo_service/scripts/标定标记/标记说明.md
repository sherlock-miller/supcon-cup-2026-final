# 标定标记使用说明

> 打印文件: `标定标记全集.pdf`（3 页 A4）
> 生成脚本: `scripts/gen_markers.py`（参数可调后重新生成）

## 第 1 页: ChArUco 标定板（相机内参标定）

- **规格**: 5×7 方格 / 方格 30mm / 内嵌 ArUco 标记 22mm / DICT_6X6_250
- **打印**: A4，**100% 比例**（不要缩放/适应页面），贴在平整硬板上（亚克力/硬纸板）
- **用途**: 相机内参标定（fx/fy/cx/cy + 畸变系数）
- **为什么用 ChArUco 而不是纯棋盘格**:
  - 抗部分遮挡（棋盘格必须完整可见才能检测）
  - 角点有唯一 ID，自动匹配，不需要整板可见
  - 相机离得近、视野装不下整板时也能标定（这是眼在手上的常见情况！）

## 第 2 页: ArUco 单标记 ×12（操作台定位基准）

- **规格**: DICT_4X4_50 / ID 0-11 / 40mm
- **打印**: 剪下单个标记，贴在操作台/夹具/物体上
- **用途**:
  - 手眼标定精度验证（识别标记 → 机械臂指到标记 → 对比误差）
  - 快速定位基准点（每个 ID 一个位置）
  - 物体位姿辅助检测（贴在目标物上）

## 第 3 页: ArUco 大标记 ×6（远距离）

- **规格**: DICT_6X6_250 / ID 0,1,2,3,10,20 / 60mm
- **用途**: 相机离目标远、或低分辨率时的稳定识别

## 现场使用建议

| 场景 | 用什么 |
|------|--------|
| 相机内参标定 | 第 1 页 ChArUco 板 |
| 手眼标定（AX=XB） | 第 1 页 ChArUco 板（或第 3 页大标记） |
| 验证标定精度 | 第 2 页单标记贴操作台 |
| 拍照位姿态参考 | 第 2 页单标记 |
